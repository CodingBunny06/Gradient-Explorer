# Getting Support

For questions about installing, running, or using Gradient Explorer:

1. Read the [README](README.md), especially the setup and supported equation syntax sections.
2. Review the [deployment guide](docs/deployment.md) if your question concerns Streamlit Community Cloud.
3. Search existing [GitHub issues](https://github.com/CodingBunny06/Gradient-Explorer/issues) for a similar question.
4. If the problem is reproducible and not security-sensitive, open an issue and include your operating system, Python version, steps to reproduce, expected behavior, actual behavior, and relevant error output.

Do not post passwords, access tokens, private data, or other secrets in issues.

For suspected security vulnerabilities, follow [SECURITY.md](SECURITY.md) and do not open a public issue.

This is an independently maintained academic project; support is provided on a best-effort basis, with no guaranteed response time.
